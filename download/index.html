Download

HazelFlix is one JavaScript file run by Node.js, with its page, icons and fonts beside it. There's nothing to install from npm.

Download (zip)View on GitHub

What you need

  • Node.js 22.5 or later
  • ffmpeg and ffprobe (on a Mac: brew install ffmpeg)
  • curl and sqlite3, for IMDb's and GeoNames' data (both come with macOS)

Start it

1. Unzip it, anywhere

A new version replaces the folder: your data is kept elsewhere.

2. Start it with your folders

./start.sh --web 0.0.0.0:8095 --library ~/Movies --library ~/Music

3. Open it

Go to http://127.0.0.1:8095 on the same machine, or the machine's address from a phone or another computer. Settings there adds folders, keys for the film databases, and which TVs show the screen saver.

Or in Docker

docker build -t hazelflix .
docker run -d --name hazelflix --network host \
  -v hazelflix-data:/data -v ~/Movies:/media/movies:ro \
  hazelflix --library /media/movies

TVs find HazelFlix by multicast, so they need --network host (Linux). In Docker, video is converted in software (x264), so it takes more of the machine than a Mac's own encoder does.

Where it runs

It's made and checked on Macs (Apple silicon) and in Docker (Linux). Its data (the database, your settings, photos and converted copies) lives in ~/Library/Application Support/HazelFlix on a Mac, ~/.local/share/hazelflix on Linux, or /data in Docker.
